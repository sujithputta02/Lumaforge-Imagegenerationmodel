# Security Policy

## Supported Versions

We actively support and fix security issues in the following versions of LumaForge:

| Version | Supported          |
| ------- | ------------------ |
| 1.1.x   | :white_check_mark: |
| 1.0.x   | :x:                |

## Reporting a Vulnerability

We take the security of LumaForge seriously. If you find a security vulnerability, please do not report it publicly in the issue tracker. Instead, please report it directly via email to:

**sujithputta02@gmail.com**

Please include the following details in your report:
* A description of the vulnerability and its potential impact.
* Detailed steps or a proof-of-concept script to reproduce the vulnerability.
* Any potential mitigation steps or fixes.

Once we receive your report, we will:
1. Acknowledge receipt of your report within 48 hours.
2. Work on a fix or mitigation plan.
3. Keep you informed of our progress.
4. Release a security advisory and patch once the fix is ready.
